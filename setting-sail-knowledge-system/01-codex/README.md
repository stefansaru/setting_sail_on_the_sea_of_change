# 01 — Codex (the wiki)

Atomic, cross-linked pages. **One idea per file.** Neutral voice. Every page cites
the source layer and links to its neighbors.

| Folder | Type | What goes here |
|--------|------|----------------|
| `principles/` | principle | Irreducible first principles. |
| `concepts/` | concept | Named ideas, models, distinctions (`tier: major` / `supporting`). |
| `techniques/` | technique | Concrete practices with steps. |
| `metaphors/` | metaphor | Stories, mascots, images — memory hooks. |
| `influences/` | influence | The thinkers the worldview borrows from. |
| `maps/` | — | The only non-atomic files: graph, MOCs, themes, contradictions, gaps. |

Authoring rules, templates, and the eight required page sections live in
[`../_schema/AGENTS.md`](../_schema/AGENTS.md). Copy a template from
`../_schema/templates/` to start a new page.

**To explore:** start at [`maps/knowledge-graph.md`](maps/knowledge-graph.md) or the
camel→lion→child Map-of-Content at [`maps/moc-three-metamorphoses.md`](maps/moc-three-metamorphoses.md).
