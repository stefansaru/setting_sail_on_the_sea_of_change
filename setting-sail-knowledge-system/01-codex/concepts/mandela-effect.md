> When large groups confidently "remember" something that never happened — memory is a storyteller, not a camera.

## What it is
A shared false memory. Named because many "remember" Nelson Mandela dying in prison in the
1980s (he was released in 1990 and became president). It shows memory is *reconstructive*
(see [[minds-eye-movies]]).

## How it misleads
- **Media:** the "Berenstein" Bears (actually Berenstain); a Sinbad genie film ("Shazaam") that never existed.
- **Quotes:** famous lines widely misattributed because they "feel right."
- **Everyday:** siblings "remembering" events that didn't happen; unverifiable meeting outcomes.

## How to counter it
- **Verify** against original sources before trusting memory.
- Accept memory is reconstructive, not a perfect record.
- Separate the story from the fact — "feels true" ≠ "is true."
