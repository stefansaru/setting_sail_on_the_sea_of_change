> To build a habit, strengthen each step of the loop; to break one, sabotage each step. Same four levers, opposite directions.

## Definition
Practical methods built on [[the-habit-loop]] (cue → craving → response → reward),
dramatized by [[the-habit-penguins]] (Pip builds, Pop breaks, Smokey quits smoking).

## Why it works
Because every habit runs the same four-step loop, you change a habit by acting on its
steps — not by sheer willpower. Building reinforces all four; breaking disrupts any one
(a "missing cue, craving, action, or reward weakens the loop").

## Steps
**To BUILD a good habit (Pip):**
1. **Cue** — make the trigger obvious (e.g. a scent, a visible object, a set time/place).
2. **Craving** — make it attractive (picture the reward; pair with something you want).
3. **Response** — make the action easy (start tiny — see [[two-minute-rule]]).
4. **Reward** — make it satisfying so the loop reinforces.

**To BREAK a bad habit (Pop / Smokey):**
1. **Remove the cue** — change the environment that triggers it (alarm across the room; smoke only outside).
2. **Reduce the craving** — recall the real consequences; delay (Smokey postponed each cigarette a few minutes).
3. **Make it difficult** — add friction (don't carry the cigarettes; put an obstacle in the way).
4. **Remove/replace the reward** — see what it really gives you; substitute a better reward.

## When to use it
- Installing any new behavior, or dismantling one that controls you.
- Smokey's deeper lesson: quitting is "reclaiming control" — seeing cravings as "just thoughts... not commands."

## Common mistakes
- Attacking only the response (white-knuckling) while leaving cue and craving intact.
- Building a habit with no reward (it won't stick) or breaking one without replacing its benefit (see [[breaking-a-bad-habit-but-keeping-its-benefit]], forward link — Ch.6).
- Expecting instant change instead of repeating until automatic.
