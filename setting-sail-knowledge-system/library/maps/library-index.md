## Cross-book agreements
*Where multiple books (and Setting Sail) point the same way.*
- **Mind-set shapes life** — Carnegie ("our life is what our thoughts make it") + Hill ("thoughts are things") + Setting Sail's [[the-problem-is-not-the-problem]] / [[thermostat-vs-thermometer]]. *(But note the motive split below.)*
- **Agency / responsibility** — Hill ("the responsibility is yours") + Carnegie ("cooperate with the inevitable") + [[agency-over-circumstance]] / [[you-are-the-sailor-not-the-wind]].
- **Decision & persistence** — Hill (decide fast, persist) + Setting Sail [[change-begins-with-a-decision]] / [[the-long-game]].
- **Fear/worry is a state of mind** — Hill (six ghosts of fear) + Carnegie (worry habit) + [[most-fears-are-memories]] / [[emotional-mastery]].

## Cross-book tensions
*Where authors genuinely disagree — the most valuable entries (cf. [[contradictions]]).*
- **Same lever, opposite aim:** Hill harnesses thought to *acquire wealth*; Carnegie quiets thought to *find peace*. Both say "mind shapes life," but point it in opposite directions.
- **Magical thinking vs. clear thinking:** Hill's "thoughts become things" / sixth sense vs. [[clear-thinking-under-bias]] (and Hill's reliance on [[survivorship-bias]]). → logged in [[contradictions]] (pending the author's resolution).
- **How much can you control?** Hill (near-total via thought) vs. [[agency-over-circumstance]] (your response, not the wind). A polarity.

## Shared themes (linking to the codex theme tags)
- **theme/self-authorship** — think-and-grow-rich (definite purpose), how-to-stop-worrying (be yourself).
- **theme/observer-stance** — how-to-stop-worrying (mental attitude).
- **theme/control-vs-acceptance** — how-to-stop-worrying (cooperate with the inevitable), think-and-grow-rich (responsibility).
- **theme/meaning** — how-to-stop-worrying (do good for others, gratitude).

## How to use this map
When you add a book, ask: *Which codex page does each key idea rhyme with? Where does the
author disagree with Setting Sail or another book?* Record both here. Sharp contradictions
also go in `01-codex/maps/contradictions.md` so the polarity layer keeps growing.
