# Setting Sail Knowledge System

A permanent, compounding wisdom repository reverse-engineered from the book
***Setting Sail on the Sea of Change***.

It is built to be four things at once:

1. **A personal philosophy wiki** — every idea in the book, atomized and linked.
2. **A human operating system** — principles and techniques to run a life on.
3. **A legacy archive** — a structured inheritance, especially for the author's daughter.
4. **A content engine** — raw material for books, videos, podcasts, and future AI assistants.

> This is **not** a summary of the book. It is the *worldview architecture* hidden
> beneath the chapters, made queryable, extendable, and durable beyond a lifetime.

---

## How it is organized

```
00-sources/     Immutable extraction of the manuscript — the ground truth.
01-codex/       The wiki: atomic, cross-linked pages.
  principles/   First principles the worldview rests on.
  concepts/     Named ideas, models, distinctions (major & supporting).
  techniques/   Concrete, do-this-now practices.
  metaphors/    Stories, mascots, images — the memory hooks.
  influences/   The thinkers the worldview is built from.
  maps/         The knowledge graph, Maps-of-Content, themes, contradictions, gaps.
02-legacy/      The inheritance layer — distilled wisdom in the author's voice.
03-engine/      The content-generation layer — templates, prompts, series outlines.
_schema/        The governor — rules, page templates, taxonomy, lint checklist.
```
