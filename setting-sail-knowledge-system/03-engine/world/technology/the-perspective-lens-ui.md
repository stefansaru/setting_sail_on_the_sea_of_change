> The series is shot 9:16 for Reels/Shorts, and the frame itself *is* a character's mind: hard-coded
> UI bars top and bottom turn the phone screen into the literal Perspective Lens of whoever we're
> watching through.

## Concept
Because the series is custom-tailored for **9:16 vertical** distribution, the frame is treated as the
character's **Perspective Lens** ([[the-doughnut-principle]] made literal). Structural UI modules are
hard-coded at the top and bottom edges; the central 9:16 real estate is the cinematic scene.

```
+-----------------------------------+
|  [◯] [◯] [◯]   TOP UI: CONTEXTS   |  <- Circular "Doughnut" icons
+-----------------------------------+
|                                   |
|        9:16 CINEMATIC VIEW         |  <- Active character scene
|                                   |
+-----------------------------------+
|  [▢] [▢] [▢]  BOTTOM UI: INTENTIONS|  <- Square choice icons
+-----------------------------------+
```

## Rules / mechanics
- **Top circles `[◯]` — Context elements.** The global "doughnut" of external truths; circular
  icons/pictograms/loops **pulse** to show the scene's active realities (e.g. Environment Safety,
  Underlying Existential Dread, Society Metrics).
- **Bottom squares `[▢]` — Intention elements.** The character's sharp, directional choices; square
  icons **pulse** to show the active internal alignment vector deployed in the current context.
- **Custom Lenses.** Every citizen's avatar has customizable lenses, and the audience views the
  episode *through* them — so **different characters facing the same scene show completely different
  top/bottom UI**. The format renders the Doughnut Principle directly.

## In the world / look
Diegetic, always-on chrome (`VIS-08`): circles read as soft loops, squares as sharp directives —
the **round context vs. squared intention** geometry is itself the theme. Pairs with the color
vectors (`VIS-09`) and the dual-panel / equilibrium metaphors (`VIS-10`/`VIS-11`).

## Story role
The format *is* the thesis: we never see objective reality, only a chosen lens — and switching whose
lens we're in (or watching the squares change) is a storytelling move unique to this series. A scene
re-played through a second character's UI is a built-in reveal device.

## Open questions
- Can the audience *choose* the Lens (interactive), or is it authored per shot? Sets whether this is
  a passive Reel or a branching format.
