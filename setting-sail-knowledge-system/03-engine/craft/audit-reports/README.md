# Audit Reports

Timestamped scorecards + findings produced by [`../../prompts/audit-script.md`](../../prompts/audit-script.md),
one file per run:

```
AuditReport_<title>_d<draft>_<YYYYMMDD_HHMMSS>.md
```

Keep them — comparing a short's reports across drafts is the **trend** view (gates closing,
1–5 scores rising) defined in [`../writing-requirements.md`](../writing-requirements.md). The
timestamp is the audit *start*, so back-to-back runs sort chronologically.

*(Reports are added by runs; this folder starts empty.)*
