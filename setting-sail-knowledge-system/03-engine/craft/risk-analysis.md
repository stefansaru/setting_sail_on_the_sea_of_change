# Production Ops — Strategic Risk Analysis & Mitigation

> Producing a high-concept AI vertical series demands a **software-engineering approach to creative
> assets.** Because the target audience ([[market-research]]) is intensely analytical, any break in
> visual continuity or internal logic = immediate churn. This is the framework that protects **budget,
> asset equity, and narrative integrity.** Ops-cluster sibling of [[ai-production-toolkit]] /
> [[distribution-strategy]].
>
> ⚠️ **Freshness:** specific tools/features (Flow, Gen-4 SceneBuilder, Creator Rewards) are early-2026 —
> re-verify at production time.

## 1. Core risks
- **A · Runaway budget (the regeneration multiplier).** Loose constraints push the re-roll factor from
  ~3× to ~15× per shot (chasing Raul's continuity / exact set geometry) → a $300–$1,500 season balloons
  past **$5,000** in wasted compute. ([[ai-production-toolkit]] §3.)
- **B · Audience alienation (logical "soft" writing).** Introduce airtight rules ([[the-memory-substrate|the
  Unifying Law of Fidelity]], [[parallel-pedagogy]]) then break them for plot convenience → critical fans
  call it out, killing the Ecosystem-Mandate funnel.
- **C · Tooling volatility (visual mutation).** Engines hallucinate / drift — Raul renders perfectly
  static, then his shell geometry mutates the moment he moves fast → a "cheap AI" look that betrays the
  practical, in-camera color compositions.
- **D · Algorithm suppression (the retention trap).** Fail to hook in the first **3–5 s** → the platform
  stops distributing to the sci-fi interest graph; high production value wasted on <15% retention.

## 2. Mitigation matrix
```
THE DUAL-ENGINE PRODUCTION LOOP
[1] CANON RECONCILIATION → automated script stress-tests
[2] MULTIMODAL TETHERING  → reference images fixed in the prompt
[3] SEQUENTIAL EXTENSION  → Flow/Gen-4 framerate continuity
        → highest retention / lowest budget drift
```
| Risk | Prob. | Sev. | Practical mitigation |
|------|-------|------|----------------------|
| Runaway costs | High | High | **3-Strike Reroll Limit** — after 3 failed text-to-video attempts, drop to **image-to-video** from a pre-stabilized static base. |
| Logical drift | Med | High | **Automated Canon Auditing** — run every script through an isolated LLM agent loaded **only** with the World Bible *before* rendering. → *this is [[audit-script]] + [[canon-registry]].* |
| Visual mutation | High | Med | **Asset-Tethered Prompting** — always upload Raul's static design sheet + the target set layout as simultaneous visual inputs beside the text prompt. |
| Retention drop | High | High | **The 00:00 Rule** — hardcode a visceral, unexplained crisis or extreme color-contrast jump in the first **~300 cs** of every edit ([[distribution-strategy]] §3). |

## 3. Deep-dive protocols
### The Canon Reconciliation Protocol (mitigates Risk B)
A **hard production gate**: every script blueprint passes a 3-question stress test *before* post — and
this **is** what [[audit-script]] automates against the [[canon-registry]] (it closed the 2026-06-04
audit). The quick gate:
1. **Does Raul access memory while disconnected from the Grid?** If yes, the dialogue must show **blurry,
   associative human loss**, not perfect recall ([[the-memory-substrate]]).
2. **Is time-dilation scaling with the tier?** A Tier-3 character ⇒ the real world renders **frozen /
   hyper-slow** ([[velocity-tiers]]); and high speed feels *serene*, not frantic.
3. **Is the character's internal conflict mapped to an explicit target on the [[the-macro-doughnut|Macro-
   Doughnut]] metric** (and the right hollow→solid glyph state)?

### The Sequential Extension Method (mitigates Risk C)
Never prompt isolated clips. Use **Google Flow** or **Runway Gen-4 SceneBuilder**: generate one
high-fidelity **8-second master shot** at the scene's anchor, then use **"Extend Video"** for subsequent
cuts — the engine locks motion vectors, pixel layout, and lighting, **suppressing up to ~70% of
hallucinations.**
