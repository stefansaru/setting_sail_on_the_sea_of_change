# 02 — Legacy (the inheritance layer)

This is the one place the system speaks in the **author's first-person voice**.

The codex (`01-codex/`) is deliberately neutral so it stays clean for retrieval and
reuse. This folder is the opposite: it is where the structured knowledge is
translated back into something personal — wisdom addressed to a specific person,
above all the author's daughter.

## What lives here

- `letters/` — first-person letters keyed to a codex concept ("On saying no",
  "On choosing your own values"). Each letter links to the neutral page it
  personalizes: *the codex explains the idea; the letter passes it on.*
- `for-my-daughter.md` — the master index of the inheritance, ordered by life stage
  rather than by chapter.
- `voice.md` — notes on the author's voice so the personal register can be
  reproduced faithfully by a human or an AI assistant after the author is gone.

## Relationship to the codex

> A codex page answers *"what is this idea and is it true?"*
> A legacy letter answers *"why I want you to carry this, and how I learned it."*

Start a letter from the concept it teaches; always backlink to that `[[concept-id]]`.
